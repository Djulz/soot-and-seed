# Soot & Seed

Soot & Seed is a mobile-first, deterministic grid-puzzle prototype about
harvesting resources, shaping fire paths, and protecting the land.

## Run locally

Open `index.html` in a modern browser. The app is a self-contained static
HTML/CSS/JavaScript build and uses browser `localStorage` for campaign and
custom-level data.

## Project structure

- `index.html` — production game client
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow
- `DEPLOYMENT.md` — release instructions

## Live site

After the first successful GitHub Pages deployment, the game is published at
<https://djulz.github.io/soot-and-seed/>.
